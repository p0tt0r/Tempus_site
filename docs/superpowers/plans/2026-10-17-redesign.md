# Редизайн УМЦ «Темпус» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Новая визуальная система на всех страницах (Golos Text, цвета логотипа, мотив «ступеней»), новая главная с автоматическим блоком программ, версия для слабовидящих — без изменения структуры сайта, адресов, запросов к API и Strapi.

**Architecture:** Новые стили живут в `src/styles/` (токены, база, по файлу на область), подключаются из `main.tsx`; каждая задача переносит свою область из старого `src/App.css` и удаляет там заменённые правила, последняя задача удаляет остаток `App.css`. Программы для главной разбирает чистая функция `parsePrograms` из текста раздела «Образование». Версия для слабовидящих — data-атрибуты на `<html>` + CSS-переменные, настройки в `localStorage`.

**Tech Stack:** React 19, Vite 8, TypeScript 6, react-router-dom 7, react-markdown 10, vanilla CSS. Самопроверки — `node --experimental-strip-types` (Node 22.18, без новых зависимостей).

**Spec:** `docs/superpowers/specs/2026-10-17-redesign-design.md` — исполнитель читает его целиком перед первой задачей.
